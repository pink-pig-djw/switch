常用按键

鼠标：左键拖动旋转，滚轮朝指针方向缩放，右键平移，双击任意部件拉近。点击 3D 按键就是按下它；拖动摇杆可以推动摇杆。也支持 USB / 蓝牙手柄。

拖动旋转 · 滚轮缩放 · 双击拉近 · G 游玩模式 · T 隐藏文字 · F 放大
游玩模式 · 镜头已锁定鼠标只用来按键和点屏幕
想专心玩？游玩模式会锁定镜头，拖动、滚轮都不会再转动主机

键盘按键对照

ABXY 用 I / J / K / L 菱形排列，和右 Joy-Con 上的位置一一对应：上 X、左 Y、下 B、右 A。

网页快捷键：G 进入 / 退出游玩模式（镜头锁定，Esc 也能退出），T 隐藏 / 显示周围文字，F 放大游戏机（再按一次恢复），? 打开这张表。
